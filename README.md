## 📌 Sobre o projeto

O **De Olho na Rua** é um projeto acadêmico desenvolvido por estudantes do curso de **Desenvolvimento de Sistemas**, com o objetivo de facilitar a comunicação entre a **Prefeitura de Cajamar** e os cidadãos que utilizam as vias públicas do município.

A proposta consiste em uma aplicação que permita registrar problemas nas ruas, como buracos e desníveis, contribuindo para a identificação de locais que necessitam de manutenção e para o acompanhamento das solicitações realizadas pela população.

| | |
|---|---|
| 🏙️ **Área temática** | Mobilidade e cidades |
| 🏛️ **Instituição parceira** | Prefeitura do Município de Cajamar |

---

## ⚠️ Problema identificado

A falta de infraestrutura adequada nas vias públicas pode dificultar a locomoção de pedestres, motoristas e ciclistas, além de contribuir para o aumento de acidentes, problemas de segurança e impactos na saúde e na qualidade de vida dos munícipes.

Diante desse cenário, o projeto busca oferecer um **meio digital** para facilitar a comunicação das ocorrências aos órgãos responsáveis.

---

## 🎯 Objetivos

- 🤝 Facilitar a comunicação entre os cidadãos e a Prefeitura de Cajamar.
- 🕳️ Permitir o registro de buracos, desníveis e outros problemas nas vias públicas.
- 📍 Registrar a localização das ocorrências.
- 📊 Possibilitar o acompanhamento do status das solicitações.
- 🛠️ Disponibilizar uma área administrativa para atualização e monitoramento das ocorrências.
- 📨 Direcionar automaticamente os chamados à secretaria responsável, para análise e providências.

---

## ✨ Funcionalidades previstas

### 👤 Para os cidadãos

- 📝 Registro de ocorrências relacionadas à infraestrutura viária.
- 📍 Identificação da localização do problema.
- 🎫 Geração de chamados para acompanhamento.
- 🔎 Consulta ao status das ocorrências registradas.

### 🏛️ Para os gestores

- 🔐 Acesso a uma área administrativa específica.
- 👀 Monitoramento das ocorrências cadastradas.
- 🔄 Atualização do status dos chamados.
- 📨 Encaminhamento das solicitações à secretaria responsável.

> [!NOTE]
> As funcionalidades descritas representam a proposta do projeto e poderão ser ajustadas durante as etapas de levantamento de requisitos e desenvolvimento.
